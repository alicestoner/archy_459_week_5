transfer learning with a pretrained CNN

sherd_net <- nn_module(
  initialize = function() {
    self$resnet <- model_resnet18(pretrained = TRUE)
    self$resnet$fc <- nn_linear(512, 8) # fc refers to the Fully Connected layer
  },
  forward = function(x) self$resnet(x)
)

train the network

torch_manual_seed(459)

fitted <- sherd_net |>
  setup(
    loss = nn_cross_entropy_loss(),
    optimizer = optim_adam,
    metrics = luz_metric_accuracy()
  ) |>
  set_opt_hparams(lr = 0.0001) |>
  fit(train_dl, epochs = 15, valid_data = test_dl, verbose = FALSE)

library(ggplot2)

# Create confusion matrix from test_results
confusion <- test_results |>
  count(type, predicted) |>
  complete(type, predicted, fill = list(n = 0))

# Determine text color: white for dark cells (high n), black for light cells
confusion <- confusion |>
  mutate(text_color = ifelse(n > median(n), "white", "black"))

ggplot(data = confusion, aes(x = predicted, y = type, fill = n)) +
  geom_tile(color = "white") +
  geom_text(aes(label = n, color = text_color), size = 4, fontface = "bold") +
  scale_color_identity() +

Our models accuracy is not within the human range. It is actually lower than the human range in the study. I think this is a fair way to judge CNN because classifying pottery types is very difficult as they diffuse into each other, with styles gradually changing over time. Perhaps CNN is not beneficial for these types of classification.

The type Tusayan and Flaggstaff are confused most often. They are neighbors in time because they are often missclassified as each other. This suggests Tusayan and Flagstaff are very similar so they might not be two distict groups, but rather one group.
